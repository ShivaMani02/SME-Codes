JavaScript: Variables, Data Types & Operators

Core Concepts

Variables, Types, Operators & Real Logic

JavaScript helps us make pages interactive by storing data, checking conditions, and performing calculations using variables, operators, and type conversion.

let reassignable
const fixed value
typeof check type
=== strict compare

Live JS Demo

const name = "Shivansh";

const age = 24;

const status = age >= 18 ? "Adult" : "Minor";

console.log(`Hi ${name}, you are ${status}.`);

Output will appear here...

Variable Examples

  • let age = 24; → value can change
  • const name = "Shivansh"; → fixed value
  • var city = "Delhi"; → older style, avoid in modern code

Data Types

  • string → "Hello"
  • number → 25 or 99.99
  • boolean → true / false
  • null and undefined → empty or unassigned

Operators

+10 + 5 = 15
-10 - 5 = 5
*10 * 5 = 50
/10 / 5 = 2
%10 % 3 = 1
===5 === "5" → false
&&true && false → false
||true || false → true
