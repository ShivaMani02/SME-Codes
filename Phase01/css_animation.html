1. Inline CSS and Internal CSS

This paragraph is styled using inline CSS.

Inline CSS is written in the HTML tag's style attribute. Internal CSS is written inside a <style> tag in the <head>.

Inline CSS example: 
<p style="color: teal; font-weight: bold;">
  Hello students!
</p>
Internal CSS example: 
<style>
  p {
    color: teal;
    font-weight: bold;
  }
</style>

Inline CSS styles one element directly. Internal CSS can style many matching elements on the same page.

2. Button Hover and Transition

Move your mouse over the button. Click it to see the small press effect.

.demo-button {
  background-color: #00444d;
  color: white;
  transition: background-color 0.3s ease;
}

.demo-button:hover {
  background-color: #00717d;
}

.demo-button:active {
  transform: scale(0.97);
}

Remember: :hover works when the pointer is over an element. :active applies while it is being clicked. 0.3s means 0.3 seconds.

3. Transition Duration, Delay and Timing

Duration controls how long the change takes. Delay controls how long it waits before starting. The timing function controls the speed pattern.

linear
ease
0.3s delay
/* Takes half a second */
transition: transform 0.5s;

/* Starts after a 0.3 second delay */
transition: transform 0.5s ease 0.3s;

/* Common timing values */
transition: transform 0.5s linear;
transition: transform 0.5s ease;

Common timing values: linear = steady speed; ease = starts and finishes gently; ease-in = starts slowly; ease-out = finishes slowly.

  • skew(5deg) — slants it.

6. Keyframes Animation

Fade in once
Changing colour
Bounce
/* Fade in: invisible to visible */
@keyframes fadeIn {
  from { opacity: 0; }
  to   { opacity: 1; }
}

.fade-box {
  animation: fadeIn 1.5s ease;
}

/* Change colour in three stages */
@keyframes changeColor {
  0%   { background-color: #00444d; }
  50%  { background-color: #00a3ad; }
  100% { background-color: #00444d; }
}

.color-box {
  animation: changeColor 3s infinite;
}

/* Move up and down */
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-12px); }
}

.bounce-box {
  animation: bounce 1.5s infinite;
}

@keyframes defines the animation steps. from and to mean start and end. Percentages allow middle steps. infinite repeats the animation continuously.

7. Image Zoom on Hover

.image-card {
  overflow: hidden;
}

.image-card img {
  width: 100%;
  transition: transform 0.3s ease;
}

.image-card:hover img {
  transform: scale(1.08);
}

The image zooms in when hovered. overflow: hidden hides the part that goes outside the image box. The sample image requires an internet connection.

8. Quick Recap

  • style="..." — inline CSS, written inside an HTML element.
  • <style> — internal CSS, written in the HTML head.
  • :hover — style applied when the pointer is over an element.
  • :active — style applied while an element is being activated.
  • transition — makes a property change happen smoothly.
  • transform — moves, scales, rotates or slants an element.
  • @keyframes — defines the stages of an animation.
  • animation-duration — sets how long one animation cycle takes.
  • animation-iteration-count — sets how many times an animation repeats; infinite repeats forever.

Teaching tip: Change one value at a time (such as 0.3s, scale(1.1), or translateY(-6px)) and ask students to predict what will happen.
