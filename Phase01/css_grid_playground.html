🧠 What to notice

          

            
Columns
              
Tracks run vertically. Each column is a track between two grid lines.

            

            
fr
              
A fraction of available space. 2fr 1fr gives a 2:1 split.

            

            
gap
              
Space between rows and columns; it is not extra padding inside each card.

            

            
span
              
A grid item can occupy more than one column or row.

            

            
Responsive
              
Media queries change the layout when the viewport crosses a breakpoint.

            

            
Mobile-first
              
Start with one column, then add columns as the screen gets wider.

The strings in grid-template-areas act like a visual
          map. Repeating a name makes that area span multiple cells.

        
grid-template-columns: 2fr 1fr;
grid-template-areas:
  "header header"
  "nav    nav"
  "main   sidebar"
  "footer footer";
